# Avaliação de Desempenho de Árvores

## Compilação e Execução do Trabalho

No ambiente Linux, podem ser realizadas diretamente pelo script BASH `out.sh`:

```bash
./out.sh
```

Ou separadamente:

- **Código em C**:

```bash
gcc main.c src/avl.c src/b.c src/rubro-negra.c src/conjunto.c -o main
./main
```

- **Gráficos por Python**:

```bash
source .venv/bin/activate
python graficos.py
```
